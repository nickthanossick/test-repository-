INSTALL KAISE KARE (How to install)
  1. Is zip ko extract karo (Right click -> Extract All).
  2. "IGMC Night Watch Setup.exe" par double click karo.
  3. Agar Windows "Windows protected your PC" dikhaye:
       "More info" -> "Run anyway" dabao.
     (Ye isliye aata hai kyunki installer abhi code-signing certificate se
      signed nahi hai. Game safe hai.)
  4. Next -> I Agree -> Install -> Finish.
  5. Desktop par "IGMC Night Watch" icon se game chalao.

ZAROORI (Requirements)
  - Windows 10 ya 11 (64-bit)
  - Microsoft Edge (Windows mein pehle se hota hai) ya Google Chrome
  - Internet connection jab game start ho (hospital ka 3D model aur
    chudail ka model online se load hote hain)
  - Achha graphics card ho to best; laptop par charger laga ke khelo

CONTROLS
  W A S D   chalo            SHIFT   bhaago (wo sunti hai)
  Mouse     dekho            F       torch
  E         use / darwaza    R       torch ka cell badlo
  P         (baar baar)      mantra
  TAB       objective        ESC     pause
  Game full screen mein khulta hai. Band karne ke liye: ESC -> Menu, ya Alt+F4.

2 PLAYER ONLINE (Co-op + Voice chat)
  1. Dono PC par game install karo aur kholo.
  2. Player 1: menu mein "2 Player · Online" -> "Room banao".
     Ek 5 letter ka ROOM CODE milega — dost ko bhejo (WhatsApp etc.).
  3. Player 2: "2 Player · Online" -> code daalo -> "Join karo".
  4. Mic ki permission maange to "Allow" dabao (voice chat ke liye).
  5. "DOST JUD GAYA" aane ke baad Player 1 "Enter IGMC" dabaye —
     dono ek saath shuru honge.
  - V = mic on/off.  Dost ki awaaz uski jagah se aati hai (door = dheemi).
  - Har player ki apni Naina hai — dono ke peeche. Dost ki Naina bhi
    tujhe pakad sakti hai.
  - Kaam aadha-aadha: objective mein "Tera hissa" dikhega.
  - Tu gira aur dost zinda hai -> 5 sec mein uske paas uthega.
  - Kuch college/office WiFi par connection na bane to dusra network try karo.

SAVE
  Game ka save tumhare computer par apne aap rehta hai.

UNINSTALL
  Start Menu -> NIKJYAR Studios -> "Uninstall IGMC Night Watch"
  ya Settings -> Apps -> IGMC Night Watch -> Uninstall.
