## 🧩 The Thinking OS — 30-second version (STRIDES)

1. **S**top — 10-sec pause, emotion label karo
2. **T**ame/Frame — asli sawaal kya hai?
3. **R**estructure — MECE buckets + issue tree
4. **I**nfer/Reason — base rates + second-order effects
5. **D**ecide — expected value; 1-way vs 2-way door
6. **E**xamine — inversion + pre-mortem + red-team
7. **S**et & review — decision journal + feedback loop

Full detail → [`00-thinking-operating-system.md`](00-thinking-operating-system.md)

## ⚔️ Lethal Placement Machine — core idea

Aap data control karte ho + 230+ offers + big-company focus. Isko **system** bana do:

- **Own the system** → team ka single source of truth aap banao (pipeline tracker, offer stages).
- **Big-company playbook** → research → referral map → tailored outreach → interview-prep pipeline.
- **Force multiplier** → apne process pe doosron ko productive banao; aap team ka *operating system* ban jao.

Full → [`04-placement-lethal-playbook.md`](04-placement-lethal-playbook.md)

> **Ethical guardrail:** Yahan "lethal" ka matlab hai *itni value banao ki log aap pe depend karein* —
> **best builder + owner** ban ke, na ki teammates ko rok ke ya data chhupa ke nuksan pahunchana.
> Real, durable leverage sirf competence + systems + results se aata hai.
