# Day 6 — Thinking, Fast and Slow — Daniel Kahneman ⚠️
**Phase 1: Bias & mind** | **~500 pages** | **Read strategy:** ANCHOR BOOK — Part 1 & 3 poori; Part 2 key chapters; Part 4-5 skim. Notes pe zyada time.

## Kyun padhni hai
Ye Phase 1 ka **shikhar**. Nobel-winner ka kaam — System 1 (fast, auto, emotional) vs System 2 (slow, effortful, logical). Ye framework baaki sab biases ko ek chhat ke neeche laata hai.

## Key ideas (dhyaan idhar)
- **System 1 vs System 2** — kab kaun chalta hai; galtiyan zyादातर System 1 se.
- **WYSIATI** ("What You See Is All There Is") — dimaag missing info ko ignore karke conclusion bana leta hai.
- **Anchoring, availability, representativeness** — 3 core heuristics.
- **Loss aversion / Prospect theory** — loss ka dard gain ki khushi se ~2x.
- **Planning fallacy** — hum hamesha time/cost under-estimate karte hain. **Regression to the mean.**

## Placement application
> **Planning fallacy:** placement timelines mein buffer rakho — sab kuch expected se slow hota hai. **Loss aversion:** candidates offer chhodne se darते hain — isko negotiation/counselling mein samjho. **WYSIATI:** decision se pehle poocho "kaunsa data main *nahi* dekh raha?"
