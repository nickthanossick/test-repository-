# Day 13 — Problem Solving 101 — Ken Watanabe
**Phase 3: Problem solving** | **~110 pages** | **Read strategy:** Sabse chhoti — 1-2 ghante. Enjoy karo.

## Kyun padhni hai
Phase 3 shuru — ab structure. Ye book (originally Japan ke school kids ke liye!) problem-solving ka core simple aur clear tareeke se sikhati hai. Perfect foundation for the heavier consulting books.

## Key ideas (dhyaan idhar)
- **Logic tree** — problem ko branches mein todo (yes/no tree, issue tree).
- **Root cause vs symptom** — asli wajah tak jao.
- **Hypothesis → test** — guess banao, phir data se check.
- **Decision tools** — pros/cons list, criteria + weight matrix.
- **Plan → Do → Check → Act** loop.

## Placement application
> "Kyun kuch candidates convert nahi ho rahe?" — ek **logic tree** banao (resume? / screen? / interview prep? / negotiation?). Har branch ka data dekho, root cause pakdo. Ye sabse actionable tool hai team ke recurring problems ke liye.
